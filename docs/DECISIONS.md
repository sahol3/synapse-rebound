# Decisions

One entry per decision: date, decision, reason, who decided.

- 2026-11-13: Renderer GL Compatibility, 1280x720 canvas_items, Nearest filter. Reason: only renderer with web export for itch.io; pixel-art default. Decided by: setup session (change freely before the first playable).
- 2026-11-13: The game is SYNAPSE // REBOUND, built from the operator's spec `docs/DESIGN.md` (Hack Club Haven Dhaka 2026, theme "Bounce Back"). Godot track only; the Ren'Py track is not started. Decided by: operator.
- 2026-11-13: Viewport changed to 1152x648 with camera zoom 3 (384x216 world view, 16 px tiles), physics 120 ticks. Reason: the Warped City tiles and sprites are 16 px and read best at an integer 3x zoom. Decided by: build session.
- 2026-11-13: Built on Godot 4.7.2, although the spec names 4.3. Reason: 4.7.2 is the installed toolchain and the code uses only 4.x APIs that 4.3 also has (unverified on 4.3). Decided by: build session.
- 2026-11-13: BDragon1727 effect sheets are used but gitignored (no-redistribution licence); every other asset is CC0 Warped City. Decided by: build session.
- 2026-11-13: Synthesized sound is not allowed (operator). All SFX are recorded Kenney CC0 samples. The spec's itch.io packs (Hove Audio, Helton Yan, Shapeforms) could not be downloaded because itch.io returned 522/429 from this machine; they can replace Kenney samples cue by cue later. Decided by: operator, applied by build session.
- 2026-11-13: Godot's stretch is disabled and the `Display` autoload scales the game: whole-number art and interface scales from the real window size, a larger view on other aspect ratios, no bars. Reason: operator, "it does not adapt to different screen sizes and aspect ratios"; fractional stretch would also break the pixel grid. Decided by: operator (request), build session (method).
- 2026-11-13: Difficulty is adaptive (`Director` autoload: hit model, quit model, move model; README has the details). A new player starts at challenge 0.25, well under the original fixed numbers, and the ceiling (1.0) is above them. Reason: operator could not clear Stage 1 and asked for lightweight prediction models that keep the game engaging for everyone. Decided by: operator (request), build session (design).
- 2026-11-13: Five more Director models (parry timing, room rating, assist-lever bandit, pacing wave, skill tracing). The global challenge number stays the only thing the hit model solves for; the new models only shift how it is applied (`Director.level(lever)`), each inside a hard cap (window +0.08 s, room ease 0.18, lever boost 0.20). Reason: operator asked for more prediction and modulating models. Decided by: operator (request), build session (design).
- 2026-11-13: Space pressed again in mid-air spends the air-dash straight up (steered by A/D). Not in the spec. Reason: operator could not pass Stage 3; every step there is 64 to 80 px and a jump is 55 px, so each of the 25 platforms needed a dash aimed above the head with the mouse, and no test had ever climbed it. Shift still dashes toward the cursor. Decided by: build session, open to the operator's veto.
- 2026-11-13: During Blackout one enemy fires a fast "mercy" shot. Reason: Blackout runs at quarter speed, so in the 1.5 s window an ordinary 140 px/s shot travels about 52 px and a rebound was only possible with a shot already beside the player. Decided by: build session.
- 2026-11-13: A shot that has already hit can no longer be deflected. Until now the spent shot stayed deflectable for 0.05 s of game time (0.2 s real in Blackout), so a late click sometimes gave a free rebound; MechTest T3 had been passing through that bug. The mercy shot (every challenge level, homing) is the designed replacement, and the parry recharge runs on real time during Blackout. Decided by: build session.
- 2026-11-13: Progress saving (`user://save.json`): stage, checkpoint, modules, clock, loops, stats; Continue on the title screen. Reason: operator, "there is no progress saving". Decided by: operator (request), build session (design).
- 2026-11-13: Enemy kinds have their own characters from "Sideview Sci-Fi - Patreon Collection" by Ansimuz (CC0, OpenGameArt): marine = Enforcer, bipedal unit = Stage 3 Command Enforcer, mech = Heavy, tank = sniper, flying enemy = Deflector. Before this the Enforcer and Heavy were the player's own sprite with a tint, and the sniper and Deflector were tinted turrets and drones. Reason: operator, "the villains are all the same, go for a similar pack". Same artist as Warped City, so the styles match. Decided by: operator (request), build session (pack and mapping).
- 2026-11-14: Interface typeface is m5x7 by Daniel Linssen (CC0), a downloaded file, in place of the glyph table written in code. Reason: operator asked for a found font instead of a made one. m5x7 was chosen because it has the same grid (7 px capitals, 5 px lowercase, proportional) and 37 of 92 glyphs are pixel-identical. Decided by: operator (request), build session (choice of font).
- 2026-11-14: Each stage stands for one meaning of Bounce Back (bullets, lanes, the tower, the fall) and says so on its card; deaths and rebounds are counted aloud by Sara and The Echo. The icon is a composite of shipped pack art and the m5x7 title, and the Godot icon and boot logo are replaced. Reason: operator asked for the story and theme to be woven into play and for the game's own icon. Decided by: operator (request), build session (lines, layout).
- 2026-11-14: Retention is built on true feedback about the player's own play: recoverable Lore entries, endings found, personal bests measured against the player's own history (model 9), and a way past a room after six deaths so that every voter can reach the end. No countdowns, streak loss or other pressure to stay. Reason: operator asked for stronger engagement and retention and wide appeal for the jam vote. Decided by: operator (request), build session (which mechanisms).
- 2026-11-14: Sara is voiced by a recording the operator supplies, heard through a radio filter with recorded static; lines without a take stay text. Each ending gets an epilogue page on where the characters end up. Reason: operator asked for spoken dialogue with a radio feel and for endings with more depth. Decided by: operator (request), build session (filter chain, lines, epilogue text).
- 2026-11-14: The game's own move model is shown to the player as Sara's fire control: an outline where it expects Vincent, a live hit rate, and named calls of the next move that are scored on screen. At boss phase 3 the Echo takes the model and it reads the gunship. A few jokes sit on top (a film scream, one bleeped word, a thud on a three-second death, current slang in three Echo and HUD lines), each rate-limited. Reason: operator called the game generic and asked for a unique, unpredictable angle that fits the story, plus the best of the meme sounds without overdoing it. Meme clips of real people were left out for licence reasons; slots exist for his own takes.
- 2026-11-14: The handler is a man named Saif (was Sara). Reason: the operator recorded the handler's 34 lines in his own voice and chose "Make the handler male" over keeping a woman's name on a man's voice. Saif was picked by the agent as a Dhaka name of the same length, so no HUD layout moves; it is one rename if the operator wants another. Entries above this line and `docs/DESIGN.md` still say Sara and are left as written.
